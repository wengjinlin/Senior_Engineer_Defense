## 三、核心项目实体（答辩内容的真实载体）

### 3.1 Multica 平台建设 Skills（最终项目呈现）

- `bootstrap/` — 建区脚手架（6 个）：`aicoding-workspace-setup`（一键安装主入口）、`aicoding-skills-bootstrap`（技能入库）、`aicoding-agent-bootstrap`（角色 agent 批量创建）、`aicoding-project-init`（项目初始化并绑定仓库）、`aicoding-orchestration-bootstrap`（编排层复现：autopilot 巡检 + Mika 接力）、`aicoding-harness-bootstrap`（新仓库 harness 铺设与对齐）。
- `skills/` — 运行期技能（8 个）：`aicoding-lookup-ui-reference-v2` / `v3`（Vue2/Vue3 UI 选型速查）、`aicoding-db-schema-export`（库表结构文档导出）、`aicoding-config-auth-resource-v2` / `v3`（权限资源 SQL 生成）、`aicoding-browser-qa`（报告式浏览器 QA）、`aicoding-harness-audit`（结构文档增量对账）、`aicoding-human-test-retro`（人工测试复盘归因）。
- `sunny-multica-skills_README.md` — 上述 skills 与 bootstrap 的完整说明文档（技能定位、主要使用者、新工作区安装流程）。

解析这套 skills 即可获得"多 Agent AI 编码在 Multica 平台上如何规模化落地"的完整设计。
