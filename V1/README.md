## 报告结构（主文档）

按《2026任职资格答辩报告模板-工程师、高工.md》组织：

1. **一、个人简介** — 个人信息/近三年绩效/工作经历/荣誉，均留〔待填〕占位符（定稿前填写）
2. **二、认证周期内主要业绩成果概述** — 5 个行为模块全涉及；行为要点明细 9 行（5 核心项加粗标示）；3 项重点业绩简述
3. **三、典型项目/关键事件举证** — STAR 结构：S 三大痛点 → T 目标与四大难题 → A 三步演化×四代架构×五个重难点 → R 三类成果（含量化数据表）
4. **四、AI应用与流程贡献** — 融合陈述
5. **五、核心项举证材料索引**
